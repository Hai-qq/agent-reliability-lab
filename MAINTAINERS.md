# Maintainers

| GitHub handle | Role | Scope |
| --- | --- | --- |
| [@Hai-qq](https://github.com/Hai-qq) | Repository maintainer | Code review, evidence gates, security triage, and releases |

At least one listed maintainer must approve a release. Protected-environment approval,
tag creation, and GitHub Release publication remain human actions. If the project adds
maintainers, this file must record their handle, scope, and effective pull request.

If no maintainer is available, no one should bypass branch/release protections or
publish under the project name. A succession change should be documented in a pull
request and repository settings before release authority transfers.
